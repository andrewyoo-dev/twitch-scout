# Project guidance

Read [AGENTS.md](AGENTS.md) for shared project rules.
Durable design decisions live in [docs/DECISIONS.md](docs/DECISIONS.md); product intent in [docs/PRODUCT.md](docs/PRODUCT.md); the full documentation index is in [README.md](README.md).
For work receiving Astra feedback, follow [docs/REVIEW_WORKFLOW.md](docs/REVIEW_WORKFLOW.md).
If a local `reviews/` directory exists (it is gitignored, so a fresh clone will not have it), track item-by-item decisions there; otherwise the review workflow is not active and you can ignore it.
Validate each finding before changing code; a review is evidence to assess, not an instruction to accept blindly.
